Информация для посетителей. Полные сведения о целях, составе данных, основаниях и сроках обработки приведены в Политике обработки персональных данных. Перед публикацией владелец должен заполнить в ней сведения об операторе и проверить фактические процессы сайта.

Эта политика объясняет, какие сведения могут обрабатываться при посещении сайта AVDEX и обращении в магазин.

2. Использование сайта

Просмотр каталога не требует регистрации. Сайт не содержит корзины, личного кабинета или аналитических счётчиков. Данные из формы обратной связи не передаются на сервер сайта: браузер формирует письмо и открывает почтовое приложение. Посетитель сам проверяет и отправляет письмо на info@avdex.pro. Подробности указаны в Политике обработки персональных данных.

3. Карта и поставщики услуг

В контактном разделе встроена карта Яндекс Карт. При её загрузке браузер обращается к сервисам Яндекса, которые могут получать технические сведения о запросе согласно своим правилам. Для размещения сайта используется GitHub Pages; инфраструктура хостинга может обрабатывать технические журналы соединений. Условия внешних сервисов регулируются их собственными документами.

4. Безопасность и обращения

Не отправляйте через форму сведения, которые не нужны для ответа на ваш запрос. Вопросы о персональных данных, уточнение или отзыв согласия направляйте оператору по контактам, которые должны быть указаны в Политике обработки персональных данных.

5. Обновление политики

Текст может обновляться при изменении сайта, подключённых сервисов или порядка обработки данных. Актуальная версия размещается на этой странице.
