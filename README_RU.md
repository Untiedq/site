# Сайт AVDEX — инструкция по запуску

Статический сайт на HTML, CSS и JavaScript. Сборка и серверная часть не требуются. На сайте нет цен, корзины, оформления заказа, онлайн-оплаты, форм, чата, аналитики и внешних подключаемых шрифтов/скриптов.

## 1. Заполнить данные до публикации

Откройте `site-config.js` и замените все текстовые заглушки фактическими данными:

- телефон и `phoneHref` (международный формат, например `+74951234567`);
- электронную почту;
- фактический адрес магазина и часы работы;
- полное зарегистрированное наименование организации или ФИО ИП;
- ИНН, ОГРН/ОГРНИП и юридический адрес.

В `privacy.html` заполните все поля в квадратных скобках. Опишите только те процессы обработки персональных данных, которые действительно есть у оператора. Пока поля не заполнены и текст не проверен, страницу политики нельзя считать завершённым юридическим документом.

Проверьте ассортиментные группы в `index.html`: удалите то, чего нет в магазине, и добавьте реальные направления. Не указывайте неподтверждённые бренды, наличие, сертификаты, свойства или совместимость товаров.

## 2. Публикация в GitHub Pages

1. В репозитории `Untiedq/site` откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите публикацию из ветки `main` и папки `/ (root)`, затем сохраните настройки.
3. Сайт будет открываться по адресу [https://untiedq.github.io/site/](https://untiedq.github.io/site/).
4. Для этого адреса не задавайте пользовательский домен и не добавляйте файл `CNAME`: этот файл нужен только при подключении собственного домена.
5. После включения GitHub Pages дождитесь завершения публикации. Если адрес не открывается, проверьте состояние развертывания в разделе **Actions** репозитория.
## 3. Юридические проверки перед запуском

- **Сведения о продавце.** На странице контактов необходимо указать достоверное зарегистрированное наименование продавца, адрес и режим работы. Для ИП — сведения о государственной регистрации. Проверьте применимость требований Закона РФ «О защите прав потребителей» к фактической модели торговли.
- **Русский язык и обозначение AVDEX.** С 1 марта 2026 года статья 10.1 Закона РФ «О защите прав потребителей» устанавливает требования к русскому языку для информации, предназначенной для публичного ознакомления потребителей, включая информацию на сайтах. Исключения, в частности, предусмотрены для фирменных наименований и зарегистрированных товарных знаков. Поскольку по исходным данным AVDEX не зарегистрирован как товарный знак, проверьте, является ли AVDEX зарегистрированным фирменным наименованием продавца. Если нет — не полагайтесь на исключение для товарного знака; основное публичное наименование и содержание сайта должны быть оформлены на русском языке. Дизайн использует AVDEX как исходное обозначение, поэтому юридическую приемлемость такого отображения нужно подтвердить до публикации.
- **Персональные данные.** На сайте намеренно отсутствуют формы, аналитика, карты и сторонние виджеты. Однако GitHub сообщает, что IP-адрес посетителя GitHub Pages регистрируется и хранится для безопасности. Это создаёт отдельный вопрос применения 152-ФЗ и локализации персональных данных. До запуска оцените, допустим ли GitHub Pages для вашей модели работы, и проверьте договорные документы GitHub и требования к трансграничной передаче/локализации. Не добавляйте формы сбора данных, онлайн-чат, рекламные пиксели или аналитику без отдельной правовой и технической настройки.
- **Политика и уведомление.** Если продавец выступает оператором персональных данных, необходимо проверить обязанность опубликовать политику и сведения о мерах защиты (ст. 18.1 152-ФЗ), а также обязанность направить уведомление в Роскомнадзор до начала обработки (ст. 22 152-ФЗ) либо применимость исключений.
- **Коммерческое обозначение.** Не используйте обозначения ® или формулировки «зарегистрированный товарный знак». Отсутствие регистрации товарного знака само по себе не означает, что обозначение свободно от прав третьих лиц. Перед использованием проверьте сходные обозначения и возможные права третьих лиц.
- **Содержание сайта.** Не публикуйте цены, если решили вести сайт без цен. Не добавляйте кнопку «Купить», корзину, заказ или оплату. Информация о продукции должна быть проверяемой и соответствовать документации производителей.

## 4. Изменение содержания

- Тексты и товарные категории — `index.html`.
- Контакты и реквизиты — `site-config.js`.
- Внешний вид — `styles.css`.
- Политика — `privacy.html`.

Сайт не подключает внешние библиотеки, веб-шрифты, карты и аналитику. Все основные ресурсы находятся в репозитории.
